# Spend Me Maybe

FF14の通貨やアイテムの所持数を、ゲーム画面に表示するDalamudプラグインです。通貨の貯まり具合を確認したり、アイコンから登録したコマンドを実行したりできます。

## 導入

1. Dalamud設定のカスタムプラグインリポジトリに、次のURLを追加します。

   ```text
   https://raw.githubusercontent.com/minasis-min/Minasis-Dalamud-Plugins/main/pluginmaster.json
   ```

2. プラグイン一覧から **Spend Me Maybe** をインストールします。
3. `/spendmemaybe` で設定を開き、「貨幣を追加」から表示したい項目を登録します。
4. 「レイアウト → 表示・配置」のDemoで位置を調整し、アイコンクリックでコマンドを使うときはDemoをOFFにします。

SMMの呼び出しコマンドは `/spendmemaybe` の1つです。設定画面を開きます。オーバーレイを右クリックして開くこともできます。

## 主な機能

- 通貨・アイテムのアイコンと所持数を表示。名前の表示、アイコンのみの表示、所持数とアイコンの左右入れ替えに対応します。所持数を左に置いた縦配置では、アイコンが同じ列に揃います。
- 項目ごとに、指定数以上・以下で表示や文字色を変えられます。
- 並び順、上下左右の配置方向、アイコン・文字の大きさ、間隔、背景の濃さを調整できます。
- アイコンの左クリックでコマンドを実行し、右クリックでその項目の設定を開きます。
- テレポ一覧の右クリックから、Teleporter・Life Stream用のコマンドをコピーできます。
- ログアウト中やムービー中などは自動で非表示になります。設定は自動保存されます。

## アイテムの追加と使い方

| 登録したいもの | 追加方法・使い方 |
| --- | --- |
| ギル・軍票・トームストーンなど | 「通貨リスト」から選択します。軍票など、貯まり具合を見たい通貨には指定数以上で文字色を変える設定が使えます。 |
| バイカラージェム・スクリップなど | 通貨リストを使います。交換できる数まで貯まったときだけ表示する設定もできます。 |
| 薬・食事・テレポ券・ダークマターなど | 「名前で検索」に日本語名の一部を入力して追加します。「指定数以下で表示」にすると、補充の目安にできます。 |
| クロの空想帳などの「だいじなもの」 | 「空想帳」などで検索します。「1以上で表示」と「アイコンだけ表示」を組み合わせれば、持っている間だけアイコンが出ます。 |

集計対象は現在のキャラクターの通貨、所持品の通常品（NQ＋HQ）、だいじなものです。リテイナーやサドルバッグなどの所持品は集計対象外です。

## コマンドの登録例

「貨幣設定」で対象を選び、「クリック」のコマンド欄へ入力します。DemoをOFFにしてアイコンを左クリックすると実行できます。

| コマンド | 用途 |
| --- | --- |
| `/echo 交換先を確認` | 自分のチャットに表示して、クリック動作を試す |
| `/tp リムサ・ロミンサ` | Teleporterで交換先へ向かう。行き先名は利用環境に合わせて変更 |
| `/li tp リムサ・ロミンサ` | Life Streamで交換先へ向かう |
| `/snd run "マクロ名"` | Something Need Doingに登録済みのマクロを呼び出す |

外部プラグインのコマンドを使うには、対応するプラグインを有効にしてください。1行につき1コマンドを最大5件登録でき、行末に `<wait.3>` を付けると送信後に3秒待ちます。指定できる待機は1〜60秒です。詳しくは [使い方](USAGE.md) を参照してください。

交換自動化プラグインを起動する場合は、そのプラグインの起動コマンドを登録します。普段Plugin Collectionsを使っているなら、プロファイルを切り替え、5秒待ってから起動することもできます。

```text
/xlenablecollection "ex.profile" <wait.5>
/exampleplugin
```

利用環境で `/xltoggleprofile` が使える場合は、次の形でも登録できます。こちらは現在のON・OFFを反転します。

```text
/xltoggleprofile ex.profile <wait.5>
/exampleplugin
```

`ex.profile` は実際のプロファイル名に、`/exampleplugin` は使うプラグインの起動コマンドに置き換えてください。
